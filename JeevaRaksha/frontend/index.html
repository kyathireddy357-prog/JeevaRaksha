About the project

Problem. Many people cannot quickly tell whether symptoms need urgent care, and emergency tools are scattered.

Solution. One responsive platform that explains, warns and connects people to real help.

Real and simulated features

Accounts, sessions, history, uploads and rule-based symptom guidance are real. The assistant gives real AI answers only when an API key is configured; otherwise it shows a labelled demo reply. Uploaded reports are stored but never medically interpreted. Nothing contacts emergency services automatically.

Future scope

Regional languages, hospital finder, doctor-reviewed content and integration with IoT health sensors.

Safety and privacy

Passwords are hashed. Data is stored on the server running this app, and each user can only reach their own records. Assistant questions are sent to the configured AI provider only when a key is set. This prototype makes no healthcare-compliance claims.
